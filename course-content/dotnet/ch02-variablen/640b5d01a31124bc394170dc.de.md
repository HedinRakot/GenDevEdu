Operation - eine Aktion, die mit Ihren Daten ausgeführt wird.

Zuordnungsoperation: Ein Wert eines bestimmten Typs wird einer Variablen zugewiesen.

Es gibt drei Arten der Zuweisung:

**Erste** Art der Zuweisung: Wir erstellen eine Variable und weisen ihr einen bestimmten Wert zu.

Beispiel 1:

```csharp
var header = "Ein Mensch isst kein Schweinefleisch";
```

oder

```csharp
string header = "Ein Mensch isst kein Schweinefleisch";
```

Beispiel 2:

```csharp
var menge = 5;
```

oder

```csharp
int menge = 5;
```

**Zweite** Art der Zuweisung: Wir weisen einer bereits erstellten Variablen einen neuen Wert zu. Dieser Schritt folgt nach der Erstellung der Variablen (siehe oben stehende Beispiele).

Beispiel 1:

```csharp
var header = "Ein Mensch isst kein Fleisch";
header = "Ein Mensch isst Fleisch";
```

Nach der zweiten Zuweisung wird der Wert der Variablen "header" auf "Ein Mensch isst Fleisch" geändert. Der ursprüngliche Wert "Ein Mensch isst kein Fleisch" wird auf "Ein Mensch isst Fleisch" geändert.

Beispiel 2:

```csharp
int menge = 5;
menge = 3;
```

Nach der zweiten Zuweisung wird der Wert der Variablen "menge" auf 3 geändert. Der ursprüngliche Wert 5 wird auf 3 geändert.

**Dritte** Art der Zuweisung: Wir erstellen zwei Variablen. Dann weisen wir einer Variablen den Wert der anderen zu.

Beispiel 1:

```csharp
var header = "Ein Mensch isst Schweinefleisch";
var header2 = header;
```

Wir haben zwei Variablen: "header" und "header2". In der zweiten Zeile des Codes haben wir der Variablen "header2" den Wert "Ein Mensch isst Schweinefleisch" zugewiesen.

Beispiel 2:

```csharp
var header = "Das Kind schaut einen Cartoon";
string header2 = "Langes Fernsehen schadet den Augen";
header2 = header;
```

Wir haben zwei Variablen: "header" und "header2". In der dritten Zeile haben wir der Variablen "header2" den Wert der Variablen "header" zugewiesen. Jetzt wird die Variable "header2" den Wert "Das Kind schaut einen Cartoon" haben.
