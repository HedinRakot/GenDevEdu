Eine Variable ist eine Zelle im Computerspeicher, die Informationen enthält. Die Informationen können mit verschiedenen Datentypen gespeichert werden (`int`, `bool`, `string` usw.).

Wir können nicht mit Daten arbeiten, ohne Variablen zu verwenden.

Beispielcode:

```csharp
string meinText = "Dies ist meine erste Text-Variable";
```

In diesem Beispiel haben wir eine Variable mit dem Namen "meinText" erstellt. Der Name der Variablen wird vom Programmierer gewählt. Die Variable "meinText" enthält Textdaten. Dies bestimmt den Datentyp, der vor dem Variablennamen angegeben wird.

Schauen wir uns an, wie man eine Variable erstellt.

**Methode 1:**

Schreiben Sie zuerst den Datentyp (zum Beispiel `string`, `bool` usw.). Geben Sie dann der Variablen einen Namen. Zum Schluss setzen Sie ein Semikolon ";".

"Datentyp" "Variablenname";

**Beispiele:**

```csharp
int anzahl;
bool verheiratet;
string titel1;
```

Diese Variablen haben noch keine Werte.

**Methode 2:**

Schreiben Sie zuerst `var`. Geben Sie dann der Variablen einen Namen. Zum Schluss setzen Sie ein Semikolon ";".

`var` "Variablenname";

**Beispiele:**

```csharp
var anzahl = 0;
var verheiratet = true;
var titel1 = "Dies ist der Titel";
var titel2 = "";
```

Das Wort `var` ersetzt den Datentypnamen. Es erleichtert den Schreibprozess des Codes. Damit das Programm weiß, welchen Datentyp Sie verwenden möchten, müssen Sie ein Gleichheitszeichen "=" setzen und den Wert angeben.

**Beispiele:**

1. Wenn wir möchten, dass `var` den Typ `string` hat, öffnen und schließen wir nach dem Gleichheitszeichen die Anführungszeichen.

```csharp
var titel1 = "Dies ist der Titel";
var titel2 = "";
```

2. Wenn wir möchten, dass `var` den Typ `bool` hat, schreiben wir nach dem Gleichheitszeichen `true` oder `false`.

```csharp
var verheiratet = true;
var volljaehrig = false;
```

3. Wenn wir möchten, dass `var` den Typ `int` hat, schreiben wir nach dem Gleichheitszeichen eine beliebige ganze Zahl.

```csharp
var anzahl = 0;
var gesamt = 100;
```

4. Wenn wir möchten, dass `var` den Typ `decimal` hat, schreiben wir nach dem Gleichheitszeichen eine beliebige Dezimalzahl und den Buchstaben "m".

```csharp
var kosten = 1.2m;
var kosten = 1.0m;
var kosten = 1m;
```

5. Wenn wir möchten, dass `var` den Typ `DateTime` hat, schreiben wir nach dem Gleichheitszeichen `DateTime`.

```csharp
var aktuellesDatumUhrzeit = DateTime.Now;
```

- Dieses Beispiel ist für die Anzeige der Zeit zum Zeitpunkt der Aufgabenausführung geeignet.
- Wir werden die anderen Beispiele später in der Praxis behandeln.
