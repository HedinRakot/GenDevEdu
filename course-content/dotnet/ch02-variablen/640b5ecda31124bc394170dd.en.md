Mathematical operations include addition, subtraction, multiplication, and division. (+ - * / )

Examples:

- `var sum = 1 + 2`: The result will be the integer 3 of type `int`
- `var difference = 3.5 – 1.5`: The result will be the decimal number 2.0 of type `double`
- `var expenses = 3.5m – 1.5m`: The result will be the decimal number 2.0 of type `decimal`

Remember, when using `decimal` (for large decimal and integer values), add the letter "m" to the numbers.

The results of mathematical operations will not be displayed separately in the program but will be stored in the computer's virtual memory. We will discuss what to do with these values later.
