A variable is a cell in the computer's memory that contains information. The information can be stored using different data types (`int`, `bool`, `string`, etc.).

We cannot work with data without variables.

Code example:

```csharp
string myText = "This is my first text variable";
```

In this example, we created a variable named "myText". The name of variables is chosen by the programmer. The variable "myText" holds textual data. This determines the data type indicated before the variable name.

Let's look at how to create a variable.

**Method 1:**

First, write the data type (for example, `string`, `bool`, etc.). Then give the variable a name. Finally, end with a semicolon ";".

"Data Type" "Variable Name";

**Examples:**

```csharp
int count;
bool married;
string title1;
```

These variables do not have any values.

**Method 2:**

First, write `var`. Then give the variable a name. Finally, end with a semicolon ";".

`var` "Variable Name";

**Examples:**

```csharp
var count = 0;
var married = true;
var title1 = "This is the title";
var title2 = "";
```

The word `var` replaces the data type name. It simplifies the code writing process. In order for the program to know what data type you want to use, you must put an equal sign "=" and specify the value.

**Examples:**

1. If we want `var` to have the `string` type, after the equal sign we open and close the quotes.

```csharp
var title1 = "This is the title";
var title2 = "";
```

2. If we want `var` to have the `bool` type, after the equal sign we write `true` or `false`.

```csharp
var married = true;
var adult = false;
```

3. If we want `var` to have the `int` type, after the equal sign we write any integer.

```csharp
var count = 0;
var total = 100;
```

4. If we want `var` to have the `decimal` type, after the equal sign we write any fractional number and the letter "m".

```csharp
var cost = 1.2m;
var cost = 1.0m;
var cost = 1m;
```

5. If we want `var` to have the `DateTime` type, after the equal sign we write `DateTime`.

```csharp
var currentDateTime = DateTime.Now;
```

- This example is suitable for displaying the time at the moment the task is executed.
- We will look at the remaining examples later in practice.
