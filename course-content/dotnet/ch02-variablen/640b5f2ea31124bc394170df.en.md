Comparison operations are used to check whether a condition is satisfied.

These operations include greater than, less than, greater than or equal to, less than or equal to, equal to, and not equal to (>, <, >=, <=, ==, !=). The result of these operations will always be an answer "yes" or "no" (the value `true` or `false` of type `bool`).

Example 1:

Let's assume we need to compare the price of a sweater with other prices. The price of the sweater is 500 monetary units.

```csharp
var sweaterPrice = 500;
```

Now, let's check if the price is greater than 300 monetary units.

```csharp
var priceGreater = sweaterPrice > 300;
```

The value of the variable "priceGreater" will be `true` (yes, this is true).

Now, let's check if the price is less than 500 monetary units.

```csharp
var priceLess = sweaterPrice < 500;
```

The value of the variable "priceLess" will be `false` (no, this is false, since the specified price of 500 units is equal to the sweater's price).

Now, let's check if the price is greater than or equal to 500.

```csharp
var priceLessOrEqual = sweaterPrice <= 500;
```

The value of the variable "priceLessOrEqual" will be `true` (yes, this is true, the price of the sweater is exactly 500 monetary units).

The results of the comparisons `true` and `false` will not be displayed separately in the program but will be stored in the computer's virtual memory. We will discuss how to display them on the screen later.

Example 2:

You can compare the values of two variables.

Let's assume we need to compare the prices of two types of milk: Burenka milk and "Domik in the village" milk. We want to compare the prices of these products and find out which one is cheaper. Here, we will take an example with specific prices for these products at some point in time.

```csharp
var burenka = 500;
var domik = 100;
```

To compare the values of the variables "burenka" and "domik", we write the following expression: "burenka > domik".

The code will look like this:

```csharp
var comparePrice = burenka > domik;
```

The value of the variable "comparePrice" will be `true`.
