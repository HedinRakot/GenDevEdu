Operation - an action performed on your data.

Assignment operation: a value of a specific type is assigned to a variable.

There are three types of assignment:

**First** type of assignment: we create a variable and assign a specific value to it.

Example 1:

```csharp
var header = "A person does not eat pork";
```

or

```csharp
string header = "A person does not eat pork";
```

Example 2:

```csharp
var quantity = 5;
```

or

```csharp
int quantity = 5;
```

**Second** type of assignment: we assign a new value to an already created variable. This step follows the creation of the variable (see examples above).

Example 1:

```csharp
var header = "A person does not eat meat";
header = "A person eats meat";
```

After the second operation, the value of the variable "header" will be "A person eats meat". The initial value "A person does not eat meat" will be changed to "A person eats meat".

Example 2:

```csharp
int quantity = 5;
quantity = 3;
```

After the second operation, the value of the variable "quantity" will be 3. The initial value 5 will be changed to 3.

**Third** type of assignment: we create two variables. Then we assign the value of one variable to another.

Example 1:

```csharp
var header = "A person eats pork";
var header2 = header;
```

We have two variables: "header" and "header2". In the second line of code, we assign the value "A person eats pork" to the variable "header2".

Example 2:

```csharp
var header = "The child is watching a cartoon";
string header2 = "Watching TV for long periods is harmful to your eyes";
header2 = header;
```

We have two variables: "header" and "header2". In the third line, we assign the value of the "header" variable to "header2". Now the variable "header2" will have the value "The child is watching a cartoon".
