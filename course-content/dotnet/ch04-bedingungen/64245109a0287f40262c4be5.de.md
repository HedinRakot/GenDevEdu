Stellen Sie sich vor, Sie haben ein Problem. Sie müssen den Benutzer nach seinem Alter fragen, und das Programm vergleicht es mit einem bestimmten Wert. Dann wird es den Benutzer entweder weiterlassen oder nicht.

Wenn der Benutzer jedoch sein Alter eingibt, wird das Programm es als TEXT speichern. Aber wir müssen es mit Zahlen vergleichen.

Schauen wir uns an, wie man Text in eine Zahl umwandelt. Oder anders gesagt, wie man Textdaten in numerische Daten umwandelt, damit das Programm sie verarbeiten und weiterverwenden kann.

Schauen wir uns ein Beispiel an.

Mit dem Befehl `Console.ReadLine` erhalten wir die Benutzereingaben im Format `string`.

```csharp
Console.WriteLine("Wie alt bist du?");
var alter = Console.ReadLine();
```

Wenn der Benutzer die Zahl 18 eingibt, wird der Wert der Variablen alter "18" sein.
Wir können keine Strings wie "18" mit ganzen Zahlen vergleichen. Um dies zu tun, müssen wir den String "18" in die Zahl 18 umwandeln.

Das lösen wir mit dem Befehl `Int32.Parse`.

Beispiel:

```csharp
var alter_text = Console.ReadLine();
var alter_nummer = Int32.Parse(alter_text);
if (alter_nummer >= 18)
{
    Console.WriteLine("Du bist bereits 18 Jahre alt.");
}
```

Der Befehl `Int32.Parse` wandelt den String in eine Zahl um und gibt das Ergebnis zurück. Dieser Wert kann einer bereits vorhandenen Ganzzahl-Variable vom Typ `int` zugewiesen werden. Alternativ können Sie eine neue Variable erstellen und ihr direkt den Wert zuweisen, wie wir es im obigen Beispiel gemacht haben.
