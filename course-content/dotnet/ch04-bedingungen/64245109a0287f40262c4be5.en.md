Let's imagine that you have a problem. You need the user to enter their age, and the program will compare it with the appropriate value. Then, it will either let the user continue or not.

However, when the user enters their age, the program will store it as TEXT. But we need to compare it with numbers.

Let's figure out how to convert text into a number. In other words, how to transform textual data into numeric data so the program can process and use it.

Let's break it down with an example.

Using the `Console.ReadLine` command, we get data from the user in `string` format.

```csharp
Console.WriteLine("How old are you?");
var age = Console.ReadLine();
```

If the user enters the number 18, the value of the age variable will be "18".
We cannot compare strings like "18" with integers. To solve this, we need to convert (or cast) the string "18" into the number 18.

We can solve this with the `Int32.Parse` command.

Example:

```csharp
var age_text = Console.ReadLine();
var age_number = Int32.Parse(age_text);
if (age_number >= 18)
{
    Console.WriteLine("You are already 18 years old.");
}
```

The `Int32.Parse` command converts the string into a number and returns the result. This value can be assigned to an already existing integer variable of type `int`. Alternatively, you can create a new variable and assign the result directly to it, as we did in the example above.
