`else` ist ein Befehl für einen alternativen Weg. Es kann durch die Wörter "sonst" oder "dann" ersetzt werden.

Zum Beispiel fragt das Programm: "Rauchen Sie?". Wenn Sie mit "ja" antworten, folgt es einem Szenario, das wir oben beschrieben haben. Wenn Sie mit "nein" antworten, führt es Sie auf einen anderen Weg, den mit `else`.

Beispiel für funktionierenden Code:

```csharp
Console.WriteLine("Rauchen Sie?");
var rauchen = "nein";
if( rauchen == "ja")
{
    Console.WriteLine("Sie sind Raucher");
}
else
{
    Console.WriteLine("Sie sind toll");
}
```

In diesem Beispiel haben wir die Variable rauchen mit dem Wert "nein". Das Programm sieht, dass die Antwort "nein" nicht der Bedingung entspricht und folgt daher dem `else`-Weg. Auf dem Bildschirm wird die Nachricht angezeigt: "Sie sind toll".
