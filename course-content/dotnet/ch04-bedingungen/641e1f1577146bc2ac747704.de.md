**Aufgabe 1.**

Ermitteln Sie den Namen des Benutzers. Wenn der Benutzername "admin" ist, geben Sie den Text aus: "Sie sind ein Administrator?"

**Aufgabe 2.**

Fragen Sie nach dem Geschlecht des Benutzers. Wenn der Benutzer ein Mann ist, fragen Sie, ob er verheiratet ist. Wenn der Benutzer eine Frau ist, fragen Sie, ob sie verheiratet ist.

**Aufgabe 3.**

Ergänzen Sie Aufgabe 2. Wenn der Benutzer verheiratet ist, geben Sie den Text aus: "Sie sind verheiratet."
Wenn der Benutzer ein Mann ist, geben Sie den Text aus: "Sie sind verheiratet".

**Aufgabe 4.**

Fragen Sie den Benutzer, wie alt er ist. Wenn der Benutzer unter 18 Jahre alt ist, geben Sie den Text aus: "Zugang verweigert."

**Aufgabe 5.**

Ergänzen Sie Aufgabe 4. Wenn der Benutzer 18 Jahre oder älter ist, geben Sie den Text aus: "Zugang gewährt."

**Aufgabe 6.**

Fragen Sie den Benutzer nach seinem Land. Wenn der Benutzer "RF" eingibt, geben Sie den Text aus: "Sie leben in der Russischen Föderation." Wenn der Benutzer "China" eingibt, geben Sie den Text aus: "Sie leben in China." Wenn der Benutzer "Türkei" eingibt, geben Sie den Text aus: "Sie leben in der Türkei." In allen anderen Fällen geben Sie den Text aus: "Sie leben in dem Land:" und geben Sie das Land an, das der Benutzer eingegeben hat.
