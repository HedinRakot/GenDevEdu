`Console.ReadLine` - dieser Befehl wird verwendet, wenn Sie etwas vom Benutzer wissen möchten. Der Benutzer gibt Daten ein, und sie bleiben im Programm.

Wenn Sie sich merken und verwenden möchten, was Ihr Kunde eingegeben hat, müssen Sie eine Variable verwenden.

Beispiel:

```csharp
var name = Console.ReadLine();
```

In diesem Beispiel weisen wir der Variablen `name` den Wert zu, den der Benutzer von der Tastatur eingibt.
