`if` - is a conditional command. `if` – can be replaced with the word "if".

Let's imagine that you are writing a program where you need to ask the question: “Are you over 18?” The answer to this question will be either yes or no. At this point, your program will decide which path you will take. That is, if you are over 18, the command will direct you to one path. If not, it will direct you down another path. `if` – tells us that the program has branches at this point. Like a road that was going straight but then branched into two paths. This branch is `if`.

Example of working code:

```csharp
Console.WriteLine("Do you smoke?");
var smoking = "yes";
if( smoking == "yes")
{
    Console.WriteLine("You are a smoker");
}
```

In this example, the program will output “You are a smoker” because it compared the value of the variable “smoking” with the text “yes”. Since this condition is met, the command inside the curly braces will be executed.

The code to which this condition applies is highlighted with curly braces: { }.

If you don't use curly braces, the program will only read the first line and will only apply the condition to it.
