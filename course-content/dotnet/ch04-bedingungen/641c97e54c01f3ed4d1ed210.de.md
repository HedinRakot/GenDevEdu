`if` - ist ein bedingter Befehl. `if` – kann durch das Wort "wenn" ersetzt werden.

Stellen wir uns vor, Sie schreiben ein Programm, in dem Sie die Frage stellen müssen: „Sind Sie schon 18?“ Die Antwort auf diese Frage wird entweder ja oder nein sein. An dieser Stelle wird Ihr Programm entscheiden, welchen Weg Sie einschlagen. Das heißt, wenn Sie über 18 sind, wird der Befehl Sie auf einen Weg führen. Wenn nicht, führt er Sie auf einen anderen Weg. `if` – teilt uns mit, dass das Programm an dieser Stelle verzweigt. Wie eine Straße, die geradeaus verlief, aber dann in zwei Wege verzweigte. Diese Verzweigung ist `if`.

Beispiel für funktionierenden Code:

```csharp
Console.WriteLine("Rauchen Sie?");
var rauchen = "ja";
if( rauchen == "ja")
{
    Console.WriteLine("Sie sind Raucher");
}
```

In diesem Beispiel gibt das Programm "Sie sind Raucher" aus, weil es den Wert der Variablen "rauchen" mit dem Text "ja" verglichen hat. Da diese Bedingung erfüllt ist, wird der Befehl innerhalb der geschweiften Klammern ausgeführt.

Der Code, auf den diese Bedingung angewendet wird, ist mit geschweiften Klammern hervorgehoben: { }.

Wenn Sie keine geschweiften Klammern verwenden, liest das Programm nur die erste Zeile und wendet die Bedingung nur auf diese an.
