`else` is a command for an alternative path. It can be replaced by the words "otherwise" or "then".

For example, the program asks you: "Do you smoke?". If you answer "yes", it follows one scenario, which we described above. If you answer "no", it takes you down another path, the one marked by `else`.

Example of working code:

```csharp
Console.WriteLine("Do you smoke?");
var smoking = "no";
if( smoking == "yes")
{
    Console.WriteLine("You are a smoker");
}
else
{
    Console.WriteLine("You are great");
}
```

In this example, we have the variable smoking with the value "no". The program sees that the answer "no" does not meet the condition and therefore follows the `else` path. The message displayed on the screen will be: "You are great".
