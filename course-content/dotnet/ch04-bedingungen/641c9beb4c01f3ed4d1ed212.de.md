Schauen wir uns an, wie man mehrere Wege für ein Programm oder mehrere Bedingungen erstellt.

Dazu verwenden wir den Befehl `else if`. Dieser kommt immer nach dem `if` und vor dem `else`. Er erstellt mehrere Bedingungen.

Schauen wir uns ein Beispiel an.

```csharp
Console.WriteLine("Was ist dein Familienstand?");
var familienstand = "ledig";

if( familienstand == "verheiratet")
{
    Console.WriteLine("Du bist verheiratet");
}
else if( familienstand == "ledig")
{
    Console.WriteLine("Du bist ledig");
}
else
{
    Console.WriteLine("Du bist weder verheiratet noch ledig. Vielleicht bist du geschieden oder verwitwet?")
}
```

Auf dem Bildschirm erscheint der Text: "Bist du ledig?". Es gibt mehrere Wege: Wenn der Anfangswert "verheiratet" ist, schreibt das Programm: "Du bist verheiratet". Wenn "ledig" gesetzt ist, wie in unserem Beispiel, zeigt das Programm: "Du bist ledig". In jedem anderen Fall wird das Programm antworten: "Du bist weder verheiratet noch ledig. Vielleicht bist du geschieden oder verwitwet?".

Beachte, dass der Wert der Variablen in diesem Beispiel bereits bekannt ist, aber normalerweise wird er vom Benutzer eingegeben.
