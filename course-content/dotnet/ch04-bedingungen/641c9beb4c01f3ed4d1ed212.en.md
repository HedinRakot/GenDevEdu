Let's see how to create multiple paths for a program or multiple conditions.

For this, we use the `else if` command. It always comes after the `if` and before the `else`. It creates multiple conditions.

Let's look at an example.

```csharp
Console.WriteLine("What is your marital status?");
var maritalStatus = "single";

if( maritalStatus == "married")
{
    Console.WriteLine("You are married");
}
else if( maritalStatus == "single")
{
    Console.WriteLine("You are single");
}
else
{
    Console.WriteLine("You are neither married nor single. Perhaps you are divorced or widowed?")
}
```

The text "Are you single?" will appear on the screen. There are several paths: if the initial value is "married", the program will write: "You are married". If it is "single", as in our example, the program will display: "You are single". In any other case, the program will respond: "You are neither married nor single. Perhaps you are divorced or widowed?".

Note that in this example, we already know the value of the variable, but usually, it is entered by the user.
