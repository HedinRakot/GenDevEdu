In programs you often face the task of performing certain actions a fixed number of times.

For example, if an email to the user was not sent, you might want to retry 2 more times. In this case, the repeatable command `for` helps us.

**Example.**

We want the numbers from 0 to 99 to be printed to the screen one after another.

```csharp
for (var position = 0; position < 100; position = position + 1)
{
    Console.WriteLine(position);
}
```

The following code prints the numbers from 0 to 99 line by line on the screen.

The initial value of the variable `position` is 0: `var position = 0;`

The `for` command runs as long as the value of the variable `position` is less than 100. This is defined in the condition: `position < 100;`

Each time after all the commands inside the curly braces `{ }` have been executed, the value of the variable `position` is increased by 1. This is described in the condition of the `for` command: `position = position + 1`

The values of the variable `position` change at each step as follows:

```
0+1
1+1
2+1
3+1
...
```

And so on.

It ends at 99, because if you add 1 to 99 you get 100, and that number no longer satisfies the condition.

As a result, on the screen we will see:

```
0
1
2
…
99
```
