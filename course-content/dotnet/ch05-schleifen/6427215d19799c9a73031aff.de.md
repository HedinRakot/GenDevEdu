Angenommen, wir müssen eine Umfrage für die Altersgruppe von 15 bis 21 Jahren durchführen.

Beispiel.

```csharp
var alter = Console.ReadLine();
if (alter >= 15 && alter <= 21)
{
}
```

In diesem Beispiel überprüfen wir, dass das Alter des Umfrageteilnehmers größer als 15 Jahre und kleiner als 21 Jahre ist. Dafür haben wir die speziellen Symbole **&&** verwendet.
Diese bedeuten, dass beide Bedingungen gleichzeitig erfüllt sein müssen.

Lassen Sie uns nun eine Umfrage für die Altersgruppe unter 18 Jahren und über 45 Jahren durchführen.

Beispiel.

```csharp
var alter = Console.ReadLine();
if (alter < 18 || alter > 45)
{
}
```

In diesem Beispiel überprüfen wir, dass das Alter des Umfrageteilnehmers entweder unter 18 Jahren oder über 45 Jahren liegt. Dafür haben wir die speziellen Symbole **||** verwendet.
Diese bedeuten, dass entweder die erste oder die zweite Bedingung erfüllt sein muss.
