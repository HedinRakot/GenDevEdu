Stellen wir uns vor, wir müssen die Zahlen von 10 bis 99 auf dem Bildschirm ausgeben. Wie können wir das erreichen?

Wir können die Ausführung der Bedingungen innerhalb des `for`-Befehls überspringen. Dafür verwenden wir den Befehl `continue`.

Beispiel:

```csharp
for (var position = 0; position < 100; position = position + 1)
{
    if (position < 10)
    {
        continue;
    }
    Console.WriteLine(position);
}
```

Der folgende Code gibt die Zahlen von 10 bis 99 jeweils in einer neuen Zeile auf dem Bildschirm aus.

Hier haben wir eine `if`-Bedingung hinzugefügt. Anders gesagt, wir sagen dem Programm, dass es die Befehle innerhalb der geschweiften Klammern überspringen soll, wenn der Wert der Variablen position kleiner als 10 ist.
