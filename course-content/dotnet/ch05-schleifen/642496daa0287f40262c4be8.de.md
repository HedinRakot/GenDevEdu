In Programmen tritt die Aufgabe auf, bestimmte Aktionen eine festgelegte Anzahl von Malen auszuführen.

Zum Beispiel, wenn die E-Mail an den Benutzer nicht gesendet wurde, versuchen wir es noch 2 Mal. In diesem Fall hilft uns der wiederholte Befehl `for`.

Beispiel.

Wir müssen sicherstellen, dass auf dem Bildschirm nacheinander die Zahlen von 0 bis 99 ausgegeben werden.

```csharp
for (var position = 0; position < 100; position = position + 1)
{
    Console.WriteLine(position);
}
```

Der folgende Code gibt die Zahlen von 0 bis 99 Zeile für Zeile auf dem Bildschirm aus.

Der Anfangswert der Variablen position ist 0: `var position = 0;`

Der Befehl `for` wird so lange ausgeführt, wie der Wert der Variablen position kleiner als 100 ist. Dies ist in der Bedingung festgelegt: `position < 100;`

Jedes Mal, nachdem alle Befehle in den geschweiften Klammern `{ }` ausgeführt wurden, wird der Wert der Variablen position um 1 erhöht. Dies ist in der Bedingung des `for`-Befehls beschrieben: `position = position + 1`

Die Werte der Variablen position ändern sich bei jedem Schritt wie folgt:

```
0+1
1+1
2+1
3+1
...
```

Und so weiter.

Es endet bei 99, da 100 nicht der Bedingung entspricht, wenn 1 zu 99 hinzugefügt wird.

Das Ergebnis auf dem Bildschirm wird sein:

```
0
1
2
…
99
```
