If we want to repeat an action until a required condition is met, we can use the `while` command.

**Example:**

```csharp
while (true)
{
    Console.WriteLine("Enter your age");
    var age_text = Console.ReadLine();
    var age = Int32.Parse(age_text);
    if (age > 0)
    {
        break;
    }
}
```

In this example we ask the user for their age inside the `while` command. If the user enters an age that is less than or equal to 0, the program will ask the user for their age again. This continues until the user enters a number greater than 0. The `break` command interrupts the execution of the `while` command.

Note that in this example the condition for executing the `while` command is given as the value `true`. This means that the condition is automatically always met, and the only way to stop the `while` command is to use the `break` command.

Let's now write this example using a condition:

```csharp
var age = 0;
while (age <= 0)
{
    Console.WriteLine("Enter your age");
    var age_text = Console.ReadLine();
    age = Int32.Parse(age_text);
}
```

In this example we created the variable `age` and assigned it an initial value of 0 before the `while` command runs. The `while` command stops running when the value of the variable `age` is greater than 0. We specified this inside the `while` command by writing the condition `age <= 0`.

The `break` command is not needed in this example, because we specified an explicit condition for ending the `while` command.
