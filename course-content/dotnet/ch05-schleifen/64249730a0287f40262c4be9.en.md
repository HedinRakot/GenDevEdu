Imagine that we need to print the numbers from 10 to 99 on the screen. How can we do that?

We can skip the execution of the statements inside the `for` command. For this we use the `continue` command.

**Example:**

```csharp
for (var position = 0; position < 100; position = position + 1)
{
    if (position < 10)
    {
        continue;
    }
    Console.WriteLine(position);
}
```

The following code prints the numbers from 10 to 99, each on a new line on the screen.

Here we added an `if` condition. In other words, we tell the program that if the value of the variable `position` is less than 10, it should skip the commands inside the curly braces.
