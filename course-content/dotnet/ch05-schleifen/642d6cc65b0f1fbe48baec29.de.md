Wenn wir eine Aktion wiederholen möchten, solange eine bestimmte Bedingung nicht erfüllt ist, können wir den Befehl `while` verwenden.

Beispiel:

```csharp
while (true)
{
    Console.WriteLine("Geben Sie Ihr Alter ein");
    var alter_text = Console.ReadLine();
    var alter = Int32.Parse(alter_text);
    if (alter > 0)
    {
        break;
    }
}
```

In diesem Beispiel fragen wir den Benutzer innerhalb des `while`-Befehls nach seinem Alter. Wenn der Benutzer ein Alter eingibt, das kleiner oder gleich 0 ist, wird das Programm den Benutzer erneut nach seinem Alter fragen. Dies wird fortgesetzt, bis der Benutzer eine Zahl größer als 0 eingibt. Der Befehl `break` unterbricht die Ausführung des `while`-Befehls.

Beachten Sie, dass im Beispiel als Bedingung für die Ausführung des `while`-Befehls ein Vergleich angegeben ist, und der Wert `true` (wahr). Das bedeutet, dass die Bedingung automatisch immer erfüllt ist und der einzige Weg, den `while`-Befehl zu unterbrechen, die Verwendung des `break`-Befehls ist.

Schreiben wir dieses Beispiel unter Verwendung der Bedingung:

```csharp
var alter = 0;
while (alter <= 0)
{
    Console.WriteLine("Geben Sie Ihr Alter ein");
    var alter_text = Console.ReadLine();
    alter = Int32.Parse(alter_text);
}
```

In diesem Beispiel haben wir die Variable alter erstellt und ihr zu Beginn den Wert 0 zugewiesen, bevor der `while`-Befehl ausgeführt wird. Der `while`-Befehl wird beendet, wenn der Wert der Variable alter größer als 0 ist. Dies haben wir im `while`-Befehl angegeben, indem wir die Bedingung alter <= 0 geschrieben haben.

Der `break`-Befehl ist in diesem Beispiel nicht erforderlich, weil wir eine explizite Bedingung für das Beenden des `while`-Befehls angegeben haben.
