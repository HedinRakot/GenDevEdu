If we want to interrupt the execution of the `for` command, we can use the `break` command.

**Example:**

```csharp
for (var position = 0; position < 100; position = position + 1)
{
    if (position > 10)
    {
        break;
    }
    Console.WriteLine(position);
}
```

The following code prints the numbers from 0 to 10, each on a new line on the screen.

Note that the condition `10 > 10` is not met, because 10 equals 10. Therefore the number 10 is also shown on the screen.
