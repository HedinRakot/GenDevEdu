How to install the Visual Studio programming environment:

1. Go to the Microsoft website using this link: [Microsoft Visual Studio Community Edition](https://visualstudio.microsoft.com/vs/community/)
2. Click Download.
3. Download the installer file to your computer.
4. Run the installer file.
5. Select the installation components as shown in the picture: **.NET desktop development** as well as **ASP.NET and web development**.

![Visual Studio installation setup](/VSInstallSetup.png)

6. Click Install.
