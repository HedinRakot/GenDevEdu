So installieren Sie die Programmierumgebung Visual Studio:

1. Besuchen Sie die Microsoft-Webseite über diesen Link: [Microsoft Visual Studio Community Edition](https://visualstudio.microsoft.com/de/vs/community/)
2. Klicken Sie auf Herunterladen.
3. Laden Sie die Installationsdatei auf Ihren Computer herunter.
4. Starten Sie die Installationsdatei.
5. Wählen Sie die Installationskomponenten wie auf dem Bild gezeigt: **.NET-Desktopentwicklung** sowie **ASP.NET und Webentwicklung**.

![Visual Studio Installations-Setup](/VSInstallSetup.png)

6. Klicken Sie auf Installieren.
