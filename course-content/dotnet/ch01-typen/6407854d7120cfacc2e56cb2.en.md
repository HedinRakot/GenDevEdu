In the C# programming language, the data type `bool` is used for working with boolean data. The values of this type are `true` (true) and `false` (false).

Example.

We need to determine whether the user of the program is of legal age. To do this, we can ask the user:

**"Are you already 18 years old?"**.

The answer to this question will be either "yes" or "no." To store this information, it is convenient to use the `bool` data type.
