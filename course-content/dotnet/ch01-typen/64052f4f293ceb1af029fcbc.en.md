In the C# programming language, several data types are used to work with floating-point numbers:

- `double` (Consumes less memory)
- `decimal` (Consumes twice as much memory as `double`) Most suitable for **financial calculations**, which require a large number of digits and no rounding errors.

All the above-mentioned data types are also suitable for working with integers. In cases where it is not clear in advance whether the number will be integer or floating-point, you should choose a data type for working with floating-point numbers.
