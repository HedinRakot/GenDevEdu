In the C# programming language, several data types are used to work with dates:

- `DateTime` - date and time
- `DateOnly` - date without time
- `DateTimeOffset` - date and time with timezone

The values of these data types represent dates ranging from 00:00:00, January 1, 0001, to 11:59:59, December 31, 9999, according to the Gregorian calendar.

Later, we will discuss this data type in more detail with practical examples.
