In the C# programming language, the data type `string` is used to work with text.

The size of the text is virtually unlimited.

Text data is always written inside quotation marks **" "**.

Examples of text data:

**"Masha loves Sasha. Sasha loves Masha. (Any text)."**

Empty text: **""**

If you want to write multiline text, use the special characters `\r\n`. They allow you to move to a new line.

Example: **"This is the first line.\r\nThis is the second line."**

To create a paragraph in text, use the special character `\t`.

Example: **"\tThis line starts with a paragraph."**
