Get ready, there will be a lot of numbers now.

In the C# programming language, several data types are used to work with integers:

- `short` (Numbers from -32,768 to 32,767)
- `int` (Numbers from -2,147,483,648 to 2,147,483,647)
- `long` (Numbers from -9,223,372,036,854,775,808 to 9,223,372,036,854,775,807)

**`int` is the most commonly used type for working with integers.**

The following types are rarely used:

- `ushort` (Numbers from 0 to 65,535)
- `uint` (Numbers from 0 to 4,294,967,295)
- `ulong` (Numbers from 0 to 18,446,744,073,709,551,615)

You don't need to remember these values by heart, but you should have a rough understanding of the range of values for each type.

Remember, when working with large numbers, you need to choose the correct data type to avoid losing information.

Example:

You need to calculate the total salary of employees in a company for one year.

The average salary of each employee is 100,000 currency units per month. For each employee's salary, the `int` data type is suitable.

Assume that the company has 2,000 employees.

Let's calculate the total income of all employees approximately: 100,000 currency units per month * 12 months * 2,000 employees = 2,400,000,000

Don't calculate in your head, use a calculator.

To calculate the total salary of the employees for the year, the `int` data type will no longer be suitable. In this example, the total salary exceeds the maximum value (2,147,483,647) for the `int` type. If we use `int`, it will cause an error in the program.

When working with large amounts of data, it's important to choose the most compact data type. The larger the maximum possible number for a data type, the more memory is used to store it, and the slower the processing speed of such data.

Types that take up less space: `short` or `ushort`.
