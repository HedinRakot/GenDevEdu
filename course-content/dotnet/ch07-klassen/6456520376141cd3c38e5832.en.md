```csharp
class Person
{
    public string Name;
}
```

To store the data about a person's name, we need to create a variable of type `Person`.

Example.

```csharp
var girl = new Person();
```

Here we use a new command, `new`. With its help we create a new object of type `Person`, which is stored in a variable named `girl`.

Right now, no value for `Name` is set for the `girl`. Let's set the girl's name.

```csharp
girl.Name = "Maria";
```

Now the value of `Name` on the variable `girl` is "Maria".

Let's now create a second Person object.

Example.

```csharp
var girl = new Person();
girl.Name = "Maria";

var boy = new Person();
boy.Name = "Alex";
```

Now we have two variables of type `Person`. The variable `girl` contains the name "Maria". The variable `boy` contains the name "Alex". These two variables are in no way connected to each other. Changing the name in one place will not cause a change in the other.

Let's now add an age to our class `Person`.

```csharp
class Person
{
    public string Name;
    public int Age;
}
```

Example.

```csharp
var girl = new Person();
girl.Name = "Maria";
girl.Age = 18;
```

Now the variable `girl` stores not only information about her name, but also about her age.

We can add an unlimited number of characteristics to our class `Person`, using any data types that were created earlier (`string`, `int`, as well as other classes). We'll look at examples of using classes inside other classes later.
