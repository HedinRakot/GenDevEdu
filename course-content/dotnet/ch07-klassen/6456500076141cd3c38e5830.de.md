Um einen neuen Datentyp zu beschreiben, muss man das Wort `class` schreiben und seinen Namen angeben.

```csharp
class Person
{
}
```

Das beschreibt einen neuen Datentyp mit dem Namen `Person`. Diese Klasse enthält keine Funktionen und kann keine Daten speichern.

Fügen wir dieser Klasse die Möglichkeit hinzu, Informationen über den Namen einer Person zu speichern.

Beispiel.

```csharp
class Person
{
    public string Name;
}
```

Jetzt können wir Informationen über den Namen einer Person speichern.
