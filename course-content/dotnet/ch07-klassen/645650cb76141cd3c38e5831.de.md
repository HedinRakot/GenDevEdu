```csharp
class Person
{
    public string Name;
}
```

Im Beispiel haben wir vor dem Datentyp `string` das Wort `public` geschrieben. Es zeigt an, dass die Daten über den Namen der Person im Code gelesen und geändert werden können.

Wenn wir es durch das Wort `private` ersetzen, sind die Daten außerhalb der Klasse `Person` weder lesbar noch änderbar.

`private` wird hauptsächlich verwendet, um den Zugriff auf Informationen einzuschränken (zum Beispiel auf Passwörter) und um die interne Umsetzung von Abläufen zu verbergen (zum Beispiel, wenn du komplexe Berechnungen durchführst, den Benutzer aber nur das Endergebnis interessiert).
