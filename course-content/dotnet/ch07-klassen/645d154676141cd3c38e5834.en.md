Functions are often used in classes.

Let's add a function to the class `Person` that returns the home address.

Example.

```csharp
class Person
{
    public string City;
    public string Street;
    public string HouseNumber;

    public string Address()
    {
        return City + ", " + Street + " " + HouseNumber;
    }
}
```

We added the function `Address`, which assembles the address from the information about the city, street, and house number.

Usage example.

```csharp
var resident = new Person();
resident.City = "Berlin";
resident.Street = "Hauptstrasse";
resident.HouseNumber = "1";

var address = resident.Address();
Console.WriteLine(address);
```

The program will print "Berlin, Hauptstrasse 1" to the screen.
