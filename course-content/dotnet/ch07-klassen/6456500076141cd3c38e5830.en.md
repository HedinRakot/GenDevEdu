To describe a new data type, you need to write the word `class` and specify its name.

```csharp
class Person
{
}
```

This describes a new data type named `Person`. This class contains no functions and cannot store data.

Let's add to this class the ability to store information about a person's name.

Example.

```csharp
class Person
{
    public string Name;
}
```

Now we can store information about a person's name.
