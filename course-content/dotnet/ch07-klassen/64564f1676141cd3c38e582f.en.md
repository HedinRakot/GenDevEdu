A class is a means of storing and grouping together different data types and functions. When we create a new class, we get a new data type. It can be used just like other data types (`string`, `int`, etc.).

**What are classes for?**

- Grouping different functions together
- Storing data
- Restricting access to data (for example, read-only)

We have already used classes when we interacted with the user through the commands `Console.ReadLine` and `Console.WriteLine`. In this case, `Console` is a class. `ReadLine` and `WriteLine` are functions of the `Console` class.
