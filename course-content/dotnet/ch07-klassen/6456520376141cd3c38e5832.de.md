```csharp
class Person
{
    public string Name;
}
```

Um die Daten zum Namen einer Person zu speichern, müssen wir eine Variable vom Typ `Person` erstellen.

Beispiel.

```csharp
var maedchen = new Person();
```

Hier verwenden wir den neuen Befehl `new`. Mit seiner Hilfe erstellen wir ein neues Objekt vom Typ `Person`, das in einer Variablen mit dem Namen `maedchen` gespeichert wird.

Im Moment ist für das `maedchen` noch kein Wert für `Name` festgelegt. Legen wir den Namen des Mädchens fest.

```csharp
maedchen.Name = "Maria";
```

Jetzt ist der Wert von `Name` bei der Variablen `maedchen` gleich "Maria".

Erstellen wir nun ein zweites Person-Objekt.

Beispiel.

```csharp
var maedchen = new Person();
maedchen.Name = "Maria";

var junge = new Person();
junge.Name = "Alex";
```

Jetzt haben wir zwei Variablen vom Typ `Person`. Die Variable `maedchen` enthält den Namen "Maria". Die Variable `junge` enthält den Namen "Alex". Diese beiden Variablen sind in keiner Weise miteinander verbunden. Eine Änderung des Namens an einer Stelle führt nicht zu einer Änderung an der anderen Stelle.

Fügen wir nun das Alter zu unserer Klasse `Person` hinzu.

```csharp
class Person
{
    public string Name;
    public int Alter;
}
```

Beispiel.

```csharp
var maedchen = new Person();
maedchen.Name = "Maria";
maedchen.Alter = 18;
```

Jetzt sind in der Variablen `maedchen` nicht nur Informationen über ihren Namen gespeichert, sondern auch über ihr Alter.

Wir können unserer Klasse `Person` beliebig viele Eigenschaften hinzufügen und dabei alle bereits zuvor erstellten Datentypen verwenden (`string`, `int` sowie andere Klassen). Beispiele für die Verwendung von Klassen innerhalb anderer Klassen schauen wir uns später an.
