```csharp
class Person
{
    public string Name;
}
```

In the example, we wrote the word `public` before the data type `string`. It indicates that the data about the person's name can be read and modified in the code.

If we replace it with the word `private`, then the data will not be readable or modifiable outside the `Person` class.

`private` is mainly used to restrict access to information (for example, to passwords) and to hide the internal implementation of processes (for example, if you are performing complex calculations but the user is only interested in the final result).
