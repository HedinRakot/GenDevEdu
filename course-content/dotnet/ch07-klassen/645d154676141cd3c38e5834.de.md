In Klassen werden häufig Funktionen verwendet.

Fügen wir der Klasse `Person` eine Funktion hinzu, die die Wohnadresse zurückgibt.

Beispiel.

```csharp
class Person
{
    public string Stadt;
    public string Strasse;
    public string Hausnummer;

    public string Adresse()
    {
        return Stadt + ", " + Strasse + " " + Hausnummer;
    }
}
```

Wir haben die Funktion `Adresse` hinzugefügt, die die Adresse aus den Informationen über Stadt, Straße und Hausnummer zusammensetzt.

Anwendungsbeispiel.

```csharp
var bewohner = new Person();
bewohner.Stadt = "Berlin";
bewohner.Strasse = "Hauptstrasse";
bewohner.Hausnummer = "1";

var adresse = bewohner.Adresse();
Console.WriteLine(adresse);
```

Das Programm gibt auf dem Bildschirm "Berlin, Hauptstrasse 1" aus.
