Let's look at an example of a function that returns the user's name.

```csharp
string UserName()
{
    Console.WriteLine("What's your name?");
    var name = Console.ReadLine();

    return name;
}
```

This function prints a question on the screen, and then the user enters some text.

We stored the user's name in the variable `name`, which is only available inside the `UserName` function and nowhere else.

**Remember:** if you create a variable inside a function, it will only be available within that function. It will not be active in any other part of the program.

The result of our function is the text value of the variable `name`.
