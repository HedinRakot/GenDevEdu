Functions almost always return a result. The result is data of some specific type (`string`, `bool`, and so on).

This is what a function that returns text data looks like — more precisely, an empty string.

```csharp
string EmptyText()
{
    return "";
}
```

Let's break down what a function consists of.

First we specify the data type. The function must return a result of this type, that is, this is the data type we get as output once the function has run.

Then comes the name of the function.

```csharp
«return value type» «function name»()
{
    « Operations »

    return «result of the specified type»;
}
```

The `return` command is mandatory for every function. With this command we return the result of the function's work. The `return` command can loosely be translated as the word "give back".
