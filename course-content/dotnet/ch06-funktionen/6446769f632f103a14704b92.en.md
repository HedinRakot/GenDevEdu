Function parameters are used to perform various operations with information entered by the user or coming from a database.

Imagine you are writing a program for an online shop. The user has entered their name, order, and payment method in different places. A function is used to bring all of this data together in one place.

Let's take a closer look at what a function with parameters looks like.

Example 1:

```csharp
string customerData(string name, string order, string paymentMethod)
{
    return name + " " + order + " " + paymentMethod;
}
```

This function gathers all of the specified data.

To print the gathered material to the screen, we proceed as follows. We introduce a new variable `var allData`, which will store all the information.

Example 2:

```csharp
var allData = customerData(name, order, paymentMethod);
Console.WriteLine(allData);
```

Now we will see all the requested data on the screen.

Let's look at one more example. You need to make a simple calculator that adds two numbers.

```csharp
int calculator(int number1, int number2)
{
    return number1 + number2;
}
```

```csharp
Console.WriteLine("Enter a number");
var number1Text = Console.ReadLine();

Console.WriteLine("Enter the second number");
var number2Text = Console.ReadLine();

var number1 = int.Parse(number1Text);
var number2 = int.Parse(number2Text);

var sum = calculator(number1, number2);
Console.WriteLine(sum);
```

First we asked the user to enter one number, then a second one. Then we converted the values from the text type to a numeric type using the `int.Parse` command. After that we used the function we had already written earlier. In the end, we will see the sum of the two numbers on the screen.
