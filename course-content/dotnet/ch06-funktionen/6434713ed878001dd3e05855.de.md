Schauen wir uns nun an, wie man die Funktion `Benutzername` aus dem vorherigen Kapitel verwendet.

Zuerst schreiben wir die Funktion selbst:

```csharp
string Benutzername()
{
    Console.WriteLine("Wie heißt du?");
    var name = Console.ReadLine();

    return name;
}
```

Jetzt schreiben wir eine Anweisung, damit die Funktion auch verwendet wird. Beachte: Die Funktion wird im Moment nirgends verwendet. Deshalb erscheint auf dem Bildschirm nichts.

Damit die Funktion ausgeführt wird, musst du ihren Namen, runde Klammern und ein Semikolon schreiben:

```csharp
Benutzername();
```

In diesem Fall haben wir das Ergebnis unserer Funktion nicht im Speicher des Programms abgelegt. Lass uns das beheben, indem wir folgenden Code schreiben.

```csharp
var name = Benutzername();
```

Wir haben eine neue Variable `name` erstellt. Das Ergebnis unserer Funktion wird jetzt in der Variablen `name` gespeichert.

Verwechsle sie NICHT mit der Variablen innerhalb der Funktion selbst.

Das vom Benutzer eingegebene Ergebnis der Funktion wird nun in der neuen Variablen gespeichert, und wir können es leicht weiterverwenden.

```csharp
Console.WriteLine("Du heißt " + name);
```

Funktionen kann man beliebig oft aufrufen.

Beispiel:

```csharp
var name = Benutzername();
Console.WriteLine("Du heißt " + name);

var name2 = Benutzername();
Console.WriteLine("Du heißt " + name2);
```

In diesem Beispiel haben wir die Funktion `Benutzername` zweimal aufgerufen. Damit haben wir den Benutzer zweimal hintereinander nach seinem Namen gefragt.
