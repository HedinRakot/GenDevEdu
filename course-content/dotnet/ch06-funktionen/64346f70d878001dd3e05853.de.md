Funktionen geben fast immer ein Ergebnis zurück. Das Ergebnis sind Daten eines bestimmten Typs (`string`, `bool` usw.).

So sieht eine Funktion aus, die Textdaten zurückgibt, genauer gesagt einen leeren Text.

```csharp
string LeererText()
{
    return "";
}
```

Schauen wir uns an, woraus eine Funktion besteht.

Zuerst geben wir den Datentyp an. Die Funktion muss ein Ergebnis dieses Typs zurückgeben, das heißt, diesen Datentyp erhalten wir am Ende, wenn die Funktion ausgeführt wurde.

Danach kommt der Name der Funktion.

```csharp
«Typ des Rückgabewerts» «Name der Funktion»()
{
    « Operationen »

    return «Ergebnis des angegebenen Typs»;
}
```

Der Befehl `return` ist für jede Funktion verpflichtend. Mit diesem Befehl geben wir das Ergebnis der Funktion zurück. Den Befehl `return` kann man sinngemäß mit dem Wort "gib zurück" übersetzen.
