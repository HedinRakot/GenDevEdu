Programmers usually solve complex problems. To do this, they combine several operations into a single group. That group is exactly what a function is.

A function can be made up of any number of operations. The programmer comes up with the names for functions based on the task at hand.

What are functions for?

1. To combine commands into a single group.

2. To reuse that function later in different parts of the program.

For example, suppose you have written a function for logging in to a website. This function compares the password entered by the user with the one stored in the system. The very same function is then also used when you want to change your password, because you are always required to enter your old password.
