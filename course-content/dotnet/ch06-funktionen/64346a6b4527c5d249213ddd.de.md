Normalerweise lösen Programmierer komplexe Aufgaben. Dazu fassen sie mehrere Operationen zu einer einzigen Gruppe zusammen. Genau diese Gruppe ist eine Funktion.

Eine Funktion kann aus beliebig vielen Operationen bestehen. Die Namen für Funktionen denkt sich der Programmierer je nach Aufgabe aus.

Wofür braucht man Funktionen?

1. Um Befehle zu einer einzigen Gruppe zusammenzufassen.

2. Um diese Funktion später an verschiedenen Stellen des Programms wiederzuverwenden.

Stell dir zum Beispiel vor, du hast eine Funktion für die Anmeldung auf einer Website geschrieben. Diese Funktion vergleicht das vom Benutzer eingegebene Passwort mit dem im System gespeicherten. Dieselbe Funktion wird dann auch verwendet, wenn du dein Passwort ändern möchtest, denn dabei wird ja immer verlangt, dass du dein altes Passwort eingibst.
