Now let's look at how to use the `UserName` function from the previous chapter.

First we write the function itself:

```csharp
string UserName()
{
    Console.WriteLine("What's your name?");
    var name = Console.ReadLine();

    return name;
}
```

Now let's write a statement so that the function actually gets used. Note that the function is not used anywhere right now. That's why nothing will appear on the screen.

For the function to run, you need to write its name, parentheses, and a semicolon:

```csharp
UserName();
```

In this case we did not store the result of our function in the program's memory. Let's fix that by writing the following code.

```csharp
var name = UserName();
```

We created a new variable `name`. The result of our function is now stored in the variable `name`.

Do NOT confuse it with the variable inside the function itself.

The result of the function, entered by the user, will now be stored in the new variable, and we can easily use it.

```csharp
Console.WriteLine("Your name is " + name);
```

Functions can be called an unlimited number of times.

Example:

```csharp
var name = UserName();
Console.WriteLine("Your name is " + name);

var name2 = UserName();
Console.WriteLine("Your name is " + name2);
```

In this example we called the `UserName` function twice. By doing so, we asked the user for their name two times in a row.
