**1.** Imagine you are writing a program in which you need to add up the total of three purchases. Ask the user to give you the cost of each one and write a function to get the result.

**2.** You need to ask a woman what her three daughters are called. Then print to the screen: "Your daughters are called..." (the daughters' names). Write a function with parameters for this.

**3.** Imagine you need to calculate how long it will take your new spaceship to reach some planet. Write a function that calculates how much time it will need. Assume that the speed of your rocket is 8 km/s and that it is constant. The user should enter the distance parameter themselves.

**4.** First ask the user what time it is right now. Then write a function that greets the user depending on the result: "Good morning", "Good afternoon", "Good evening", and "Good night".

**5.** Imagine you are writing a website for a swimming pool designer. You need the client to enter the length, height, and width. Calculate the volume of the pool.
