Schauen wir uns ein Beispiel für eine Funktion an, die den Namen des Benutzers zurückgibt.

```csharp
string Benutzername()
{
    Console.WriteLine("Wie heißt du?");
    var name = Console.ReadLine();

    return name;
}
```

Diese Funktion gibt eine Frage auf dem Bildschirm aus, danach gibt der Benutzer einen Text ein.

Den Namen des Benutzers haben wir in der Variablen `name` gespeichert, die nur innerhalb der Funktion `Benutzername` verfügbar ist und nirgendwo sonst.

**Merke dir:** Wenn du eine Variable innerhalb einer Funktion erstellst, ist sie nur in dieser Funktion verfügbar. In einem anderen Teil des Programms ist sie nicht aktiv.

Das Ergebnis unserer Funktion ist der Textwert der Variablen `name`.
