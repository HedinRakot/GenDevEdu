Funktionsparameter werden verwendet, um verschiedene Operationen mit Informationen durchzuführen, die der Benutzer eingegeben hat oder die aus einer Datenbank stammen.

Stell dir vor, du schreibst ein Programm für einen Online-Shop. Der Benutzer hat an verschiedenen Stellen seinen Namen, seine Bestellung und seine Zahlungsart angegeben. Damit all diese Daten an einer Stelle zusammengeführt werden, wird eine Funktion verwendet.

Schauen wir uns genauer an, wie eine Funktion mit Parametern aussieht.

Beispiel 1:

```csharp
string KundenDaten(string name, string bestellung, string zahlungsart)
{
    return name + " " + bestellung + " " + zahlungsart;
}
```

Diese Funktion fasst alle angegebenen Daten zusammen.

Um das gesammelte Material auf dem Bildschirm auszugeben, gehen wir folgendermaßen vor. Wir führen eine neue Variable `var alleDaten` ein, in der alle Informationen gespeichert werden.

Beispiel 2:

```csharp
var alleDaten = KundenDaten(name, bestellung, zahlungsart);
Console.WriteLine(alleDaten);
```

Jetzt sehen wir auf dem Bildschirm alle abgefragten Daten.

Schauen wir uns noch ein Beispiel an. Du sollst einen einfachen Rechner schreiben, der zwei Zahlen addiert.

```csharp
int Rechner(int zahl, int zahl2)
{
    return zahl + zahl2;
}
```

```csharp
Console.WriteLine("Gib eine Zahl ein");
var zahl1Text = Console.ReadLine();

Console.WriteLine("Gib die zweite Zahl ein");
var zahl2Text = Console.ReadLine();

var zahl1 = int.Parse(zahl1Text);
var zahl2 = int.Parse(zahl2Text);

var summe = Rechner(zahl1, zahl2);
Console.WriteLine(summe);
```

Wir haben den Benutzer zuerst gebeten, eine Zahl einzugeben, dann eine zweite. Anschließend haben wir die Werte mit dem Befehl `int.Parse` vom Texttyp in einen Zahlentyp umgewandelt. Danach haben wir die Funktion verwendet, die wir bereits zuvor geschrieben haben. Am Ende sehen wir auf dem Bildschirm die Summe der beiden Zahlen.
